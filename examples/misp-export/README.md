# MISP / HUNT-EX exports (reference fixtures)

Generated by `huntmd convert <hunt> --to misp` from the hunts in [`../../hunts/`](../../hunts)
— see [PROFILES.md §3](../../PROFILES.md) for the mapping.

| File | What it shows |
|---|---|
| `kerberoasting.misp.json` | context + hypothesis + one `threat-hunt-query`, `hunt-ex:*` tags, source attached |
| `kerberoasting-with-finding.misp.json` | the same, plus a `threat-hunt-finding` from [`../results/kerberoasting-run.yaml`](../results/kerberoasting-run.yaml) — `hunt-ex:outcome="inconclusive"` (the run was *suspicious*, not confirmed) and `hunt-ex:byproduct="data-source-gap"` (EDR was never examined) |
| `scattered-spider-identity-takeover.misp.json` | several query objects, identity + endpoint telemetry tags, product bindings as `tool`/`platform` |

Regenerate after changing a hunt or the exporter:

```bash
cd tools
python -m huntmd convert ../hunts/kerberoasting.md --to misp -o ../examples/misp-export/kerberoasting.misp.json
python -m huntmd convert ../hunts/kerberoasting.md --to misp --result ../examples/results/kerberoasting-run.yaml -o ../examples/misp-export/kerberoasting-with-finding.misp.json
python -m huntmd convert ../hunts/scattered-spider-identity-takeover.md --to misp -o ../examples/misp-export/scattered-spider-identity-takeover.misp.json
```

`huntmd convert examples/misp-export/kerberoasting.misp.json` returns the original
hunt.md byte-for-byte (the source rides along as an attachment). Strip the
attachment and the same command yields a TODO-marked draft built from the objects.
